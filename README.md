Добро пожаловать в официальный репозиторий проекта **Kremil RolePlay**. Проект представляет собой классическую игровую экосистему CRMP (Criminal Russia Multiplayer) со специализированным лаунчером, кастомной системой шифрования игровых ассетов и высокопроизводительным интерфейсом на базе Chromium-движка WebView2.

---

## ⚡ Ключевые особенности архитектуры

* **Premium Minimalist UI:** Интерфейс лаунчера и веб-ресурсов выполнен в строгой тёмно-серебряной палитре без лишних цветовых акцентов.
* **Движок WebView2:** Отрисовка интерфейса лаунчера использует аппаратное ускорение Chromium, обеспечивая плавные анимации и мгновенный отклик.
* **Безопасность ассетов:** Высокоскоростная AES-дешифровка основного игрового контейнера `hintergrund.krp` «на лету» при запуске клиента.
* **Глубокая оптимизация:** Архитектура лаунчера и сборки клиента адаптирована для стабильной работы даже на устаревших конфигурациях железа.

## 🖥️ Системные требования

### 🟢 Минимальные системные требования
> Обеспечивают стабильный запуск лаунчера, прогрузку интерфейса и базовую игру на минимальных настройках графики.

| Компонент | Конкретная модель / Характеристика |
| :--- | :--- |
| **Операционная система** | Windows 10 (64-bit) |
| **Процессор (Intel)** | Intel Core 2 Duo E8400 (3.00 ГГц) или Intel Core i3-530 |
| **Процессор (AMD)** | AMD Athlon II X2 250 (3.00 ГГц) или AMD Phenom II X2 555 |
| **Оперативная память** | 2 ГБ RAM |
| **Видеокарта (NVIDIA)** | NVIDIA GeForce GT 430 (1 ГБ) или GeForce 9800 GT |
| **Видеокарта (AMD)** | AMD Radeon HD 6450 (1 ГБ) или Radeon HD 5670 |
| **Интегрированное видео**| Intel HD Graphics 4000 |
| **Место на диске** | 5 ГБ свободного места (HDD / SSD) |
| **Сеть** | Скорость соединения от 5 Мбит/с |

| Компонент | Конкретная модель / Характеристика |
