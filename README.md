# 🛡️ KREMIL ROLEPLAY — OFFICIAL README

> **Kremil RP** — классический сервер CRMP. Торговля, экономика, фракции и полная свобода действий. Проект ориентирован на сохранение классической атмосферы «Криминальной России» с использованием современных технологий оптимизации лаунчера и игрового клиента.

---

## 💎 Особенности проекта

* **🚗 Классический CRMP:** Та самая атмосфера, знакомые города, классические автомобили и дух старой школы.
* **🛒 Развитая торговля:** Свободная покупка, продажа и обмен автомобилями, недвижимостью или ресурсами между игроками.
* **📈 Стабильная экономика:** Аукционы, бизнесы, заработок на работах и предприятиях с детальным балансом.
* **🏢 Системы фракций:** Вступайте в государственные структуры (Полиция, МЗ) или криминальные группировки (ОПГ) для контроля территорий.

## 🛠️ Техническая информация

* **Ограничение ОС:** Поддержка Windows 7 и 8 ограничена. Для корректного рендеринга интерфейса лаунчера на базе Chromium (движок WebView2) настоятельно рекомендуется использовать Windows 10/11 x64.
* **Архивация данных:** Быстрая расшифровка контейнера ресурсов `hintergrund.krp` по алгоритму AES критически зависит от скорости чтения накопителя. Для исключения микрофризов рекомендуется установка на SSD.
